# APIs present since 3.6 (QgsNetworkAccessManager.blockingGet/blockingPost) and 3.x
# (QgsSettings, QgsAuthMethodConfig, QgsTask); 3.28 is the oldest version still reasonable to
# support and is the one the Qt5/Qt6 compatibility layer targets. Tested on QGIS 3.44 LTR.
qgisMinimumVersion=3.28
qgisMaximumVersion=4.99
description=Shows the Milan planning rules (PGT/PTC) and constraints that apply at a clicked point.
about=Look up planning constraints at a point in the Comune di Milano. The municipal PGT map supplies NAF, ADR and ARU zoning where mapped, both parks and geological feasibility. Regione Lombardia services supply the regional PGT, PGRA flood and Natura 2000 layers. Findings and articles link to official sources. Check uncertain mappings and consult the current official documents for a parcel or proposed project. Optional Italian and English questions use Gemini (your own API key) or local Ollama. The dock shows supporting excerpts found in the supplied texts and flags answers that need source review. Privacy: in-city coordinates go to the Comune and Regione public map services. With Gemini, questions and selected planning information go to Google. Ollama runs locally. See the documentation for data coverage and provider settings.
